Core Concepts

Key Ideas to Remember

Connect the ID card analogy to Python OOP.

1

One design, many cards

A class is a reusable blueprint for creating objects.

2

Same attributes, different values

Mei's card has her data; Ali's card has his data.

3

A class is not an object

The blueprint describes objects; it is not an individual card.

4

Objects can perform actions

Methods are functions defined inside a class.

Class = Blueprint   |   Object = Individual instance
Python Code Syntax

Writing a Class in Python

Here is the code for our student ID card blueprint.

class StudentIDCard:
  # Set up a new card
  def __init__(self, name, grade, color):
    self.name = name
    self.grade = grade
    self.color = color
class StudentIDCard:

Defines the class blueprint.

__init__(...)

Sets up the attributes when a new object is created.

self.name

Stores the name on this particular object.

self refers to the particular object being initialized or used.

Object Instances

Creating Objects from the Class

Use the same blueprint to create cards for different students.

# Mei's card
card1 = StudentIDCard("Mei", "3A", "Red")

# Ali's card
card2 = StudentIDCard("Ali", "3B", "Blue")

print(card1.name)
# Output: Mei
👧

card1 — Mei's Object

name="Mei", grade="3A", color="Red"

👦

card2 — Ali's Object

name="Ali", grade="3B", color="Blue"

One class blueprint can create many independent objects.
Methods

Giving Cards Actions

Objects can store data and perform actions through methods.

class StudentIDCard:
  def __init__(self, name):
    self.name = name

  def enter_gate(self):
    print(self.name + " scanned card & entered!")

Call the method

card1 = StudentIDCard("Mei")
card1.enter_gate()
Output will appear here.
Each object calls its method using its own attribute values.
A method is a function defined inside a class.
